AI-Powered Helpdesk Assistant (RAG)
In Development

Type: AI / LLM Integration — Personal Project

Challenge: Support agents spent significant time manually searching past tickets to find relevant solutions before drafting a reply, slowing down response time and producing inconsistent answers across agents.

Solution: Designed and built a Retrieval-Augmented Generation (RAG) pipeline: ticket history is embedded and stored in PostgreSQL with pgvector for semantic search, then relevant past tickets/solutions are retrieved and passed to an LLM (OpenAI/Claude API) to generate a draft response. Built the backend, vector search, and API integration end to end, with a human-in-the-loop step so agents review and edit AI-generated drafts before sending.

Result: Turned ticket history into a searchable knowledge base and gave agents ready-to-review draft responses instead of starting from scratch — reducing time spent searching for solutions while keeping a human in control of final answers.
